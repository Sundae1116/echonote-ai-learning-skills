# Evaluation rubric

Score each dimension separately; do not hide hard failures inside an average.

| Dimension | Question | Hard failure |
|---|---|---|
| Fidelity | Is every material claim supported by the source? | Invented claim |
| Coverage | Are required key points present? | Missing thesis or major turn |
| Structure | Does the output follow the requested contract? | Missing required section |
| Compression | Is reading effort reduced without losing core meaning? | Near-copy or destructive overcompression |
| Learnability | Can the output produce useful recall questions and actions? | Vague, non-answerable cards |
| Translation | Are names, numbers, terms, and alignment preserved? | Changed number or entity |

Use a representative golden set, pairwise human preference, deterministic format checks, and a calibrated LLM judge. Keep human adjudication for disagreements and high-impact errors.
